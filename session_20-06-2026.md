### Da fare sul desktop (Intel i5-10600K)

Il desktop non ha MPS, userà CPU. Training più lento ma fattibile.

**1. Clonare/aggiornare il repo:**
```bash
cd /path/to/ci-cervical-lbc
git pull
# oppure clona fresh:
# git clone https://github.com/FrancescoCastaldi/ci-cervical-lbc.git
```

**2. Attivare venv e lanciare training:**
```bash
source .venv/bin/activate
# oppure .venv/Scripts/activate su Windows
python -c "from src.utils import get_device; print(get_device())"
# Dovrebbe stampare: [Device] CPU

# Training:
PYTHONPATH=. python src/methods/diffpir/train.py
```

**3. Dopo training**, aprire `notebooks/04_diffpir.ipynb` in VS Code con kernel `.venv` ed eseguire tutte le celle.

**4. Se i risultati sono buoni**, aggiornare il README con i valori reali.
