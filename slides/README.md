# slides/ — Oral Presentation

Contains the PowerPoint presentation and scripts to regenerate it.

## Files

| File | Description |
|---|---|
| presentazione.pptx | PowerPoint presentation (~10 slides, 13.333×7.5") |
| generate_pptx.py | Python script to regenerate slides from scratch |
| _extract_pptx.py | Utility to extract text from the existing presentation |
| Exam_Assignment/Group R.pdf | Original exam text (reference) |

## Slide Structure

1. **Cover** — title, Group R, names
2. **Objective** — deblurring + denoising of cervical cytology images; inverse problem formulation
3. **Dataset** — LBC Cervical Cancer: classes (NILM, HSIL, LSIL, SCC), 962 images, 70/15/15 split
4. **Degradation** — Gaussian blur (σ=2) + AWGN (4 levels); identical pipeline for fair comparison
5. **Method 1: TV** — L1 regularization on derivatives; λ=0.005, 150 Adam iterations; results
6. **Method 2: UNet** — encoder-decoder architecture (1.9M params); multi-noise L1 training; noise conditioning
7. **Method 3: DiffPIR** — DDPM (LightUNet 1.26M params) + DDIM sampling + FFT data-fidelity
8. **Quantitative Results** — PSNR/SSIM table for all methods and noise levels; comparative plot
9. **Qualitative Results** — side-by-side reconstruction grids; success and failure cases
10. **Conclusions** — summary, trade-offs, limitations, future work

## Regenerating the Presentation

```bash
python slides/generate_pptx.py
```

The script:
1. Generates presentazione.pptx in the same folder
2. Uses python-pptx (install with `pip install python-pptx`)
3. Includes images from `results/qualitative_slides/` (generated by `scripts/plot_results.py`)
4. Dark theme with blue (#00B4D8) and pink (#E01E79) accents

If `results/qualitative_slides/` is empty, run first:
```bash
python scripts/plot_results.py
```

## Presentation Tips

| Slide | Recommended duration | Key points |
|---|---|---|
| 1-3 | 2 min | Contextualize the medical problem |
| 4-5 | 3 min | Degradation + TV (classical baseline) |
| 6-7 | 4 min | UNet and DiffPIR (deep learning) |
| 8-9 | 4 min | Results: emphasize the fair comparison |
| 10 | 2 min | Clear conclusions, no surprises |

Total target: **15 minutes** presentation + 5 minutes Q&A.

## Results to Emphasize

- TV is best at low noise due to optimal L2+TV regularization
- UNet is the most robust across all noise levels, with SSIM always > 0.83
- UNet is 100× faster than TV and 80× faster than DiffPIR
- DiffPIR demonstrates the potential of the generative approach on the LBC dataset

## Customization

Modify `generate_pptx.py` to:
- Change colors (variables DARK, ACCENT, ACCENT2)
- Add/remove slides (modify the sequence of calls)
- Update results tables
- Replace qualitative images
